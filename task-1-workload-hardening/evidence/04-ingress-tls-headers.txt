NOTE: the security headers are NOT set with a configuration-snippet
annotation. ingress-nginx v1.9+ rejects that by default because snippets
inject raw nginx directives from a namespaced object into the shared
controller config (cf. CVE-2021-25742, CVE-2023-5044). Headers are
applied via the controller's own ConfigMap, editable only by a cluster
administrator:

$ kubectl get configmap custom-headers -n ingress-nginx -o jsonpath='{.data}'
{"Referrer-Policy":"no-referrer","X-Content-Type-Options":"nosniff","X-Frame-Options":"DENY"}
